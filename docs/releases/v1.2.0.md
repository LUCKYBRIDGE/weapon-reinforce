# Weapon Reinforce 1.2.0

상태: **릴리스 후보(Release Candidate)**  
기준 브랜치: `master` 병합 전 release PR  
공개 게임: https://luckybridge.github.io/weapon-reinforce/

## 1.2 핵심 변경

### 탐사 다양성

- 탐사 적 6종 → 7종
- NPC 3종 → 6종
- 사건 3종 → 6종
- 모든 지역에 NPC 2종 이상, 사건 2종 이상
- 청동 안개 5~6층 일반 적 후보 2종 이상
- 기존 적 60% / NPC 23% / 사건 17% 유형 비율과 적 2연속 뒤 지원 조우 보장은 유지

### 선택형 지원 조우

일부 NPC/사건은 자동 해결 대신 2택 선택을 제공한다.

- 선택형 NPC 2종
- 선택형 사건 2종
- 회복, 다음 공격, 다음 방어, 전리품 조사 중 서로 다른 결과 제공
- 선택 전 새로고침해도 같은 조우와 선택지를 복구
- 잘못된 선택 ID와 중복 보상 적용 차단

### 최종층 밸런스

전체 탐사를 일괄 약화하지 않고 최종 적 `primeval-time-shadow`의 HP 배율만 135% → 120%로 조정했다.

5,000회 시뮬레이션 기준:

- +6 최종층 생존: 3.1%
- +7 최종층 생존: 25.4%
- +7 무준비: 24.6%
- +7 여행 붕대: 36.9%
- +7 공명 손질 천: 34.7%
- +7 균열 안전 주머니: 24.6%

해당 목표 구간은 `validate:balance` 회귀 검사로 고정한다.

### 무기 전투 개성 가시화

7종 무기의 기존 전투 수치를 바꾸지 않고 화면 피드백을 강화했다.

- 고유 게임 전투 태그 7종
- 고유 공격명
- 치명타 확률·배율
- 기본 방어
- 적중 회복
- 치명타, 실제 피해 경감, 적중 회복, 지원 공격 보너스의 전투 순간 배지
- 치명타 플래시, 방어 경감 피격, 회복 공격 강조 연출

표시는 **게임 전투 효과**로 명시해 역사적 실전 성능과 구분한다.

### 강화 경제 실측

대성공·복원 무기고·타이밍 판정을 실제 런타임 규칙과 같은 공용 규칙으로 시뮬레이션한다.

20,000회 +1 → +7 완주, 복원 없음 기준:

| 타이밍 | 평균 강화 | 평균 소모 | 기준팩 예상 정답 |
| --- | ---: | ---: | ---: |
| 미입력 | 133.9회 | 14,091냥 | 167.8문제 |
| 타이밍 창 비례 | 113.7회 | 12,420냥 | 147.9문제 |
| GOOD 이상 혼합 | 89.4회 | 10,303냥 | 122.7문제 |
| 항상 PERFECT | 71.3회 | 8,621냥 | 102.6문제 |

최고 가능 단계 즉시 복원은 타이밍 창 비례 기준 강화 시도를 63.4% 줄이는 대신 총 엽전 소모를 106.6% 늘린다. 따라서 1.2에서는 강화 비용·성공률·타이밍 보너스·퀴즈 보상·복원 가격을 추가 조정하지 않는다.

## 저장 호환

1.2에서도 서버나 계정을 추가하지 않는다.

- 브라우저 `localStorage` 자동 체크포인트 유지
- 기존 JSON 저장 파일 경계 유지
- 탐사 run version 3 유지
- 선택형 조우와 전투 피드백은 기존 저장 형식에 additive 방식으로 호환
- checksum, 1MB 상한, 허용 key, import rollback 유지

## 자동 릴리스 게이트

```bash
npm ci
npm run validate:all
```

검증 범위:

- 7단계 무기·강화 규칙
- 9팩 762문항
- 저장 손상 복구·JSON 왕복
- 탐사 경제·선택 조우·전투 상태
- 최종층 및 강화 경제 시뮬레이션
- 1.2 릴리스 버전·문서 정합성
- ESLint
- 프로덕션 빌드
- 런타임 자산 allowlist·용량
