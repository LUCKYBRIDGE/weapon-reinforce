# Weapon Reinforce 탐사 시스템 1.1 계획

## 목표

`랜덤 조우 → 자동전투·NPC·사건 → 임시 전리품 → 안전 귀환 → 보관·준비물 교환 → 다음 탐사`가 한 바퀴 도는 게임 시스템을 만든다.

## 유지할 경계

- 기본 저장은 브라우저 `localStorage`, 선택 백업은 저장 데이터 파일이다.
- 엽전의 주 수입원은 퀴즈다. 탐사 전리품은 판매하지 않고 준비물 교환에만 쓴다.
- 전투는 자동 교대 방식이다. 적 상성, 수동 공격 명령, 장비 내구도는 넣지 않는다.
- 실제 역사 인물은 적으로 쓰지 않는다. 역사 사실과 게임 능력은 분리해 표시한다.
- 괴작은 강화 실패 보상품, 전리품은 탐사 보상으로 서로 다른 수집품이다.

## 시스템 규칙

### 1. 랜덤 조우 감독

- 먼저 `적 / NPC / 사건` 유형을 깊이별 비율로 뽑고, 그 안에서 개별 조우를 가중 추첨한다.
- 콘텐츠 수를 늘려도 유형 확률이 저절로 바뀌지 않아야 한다.
- 첫 조우는 적, 7층은 최종 적으로 고정한다.
- 최근 2개 ID는 다른 후보가 있을 때 반복하지 않는다.
- 적 조우가 두 번 연속이면 다음 중간층은 NPC 또는 사건으로 정해 억울한 장기 연속 사망을 줄인다.
- 선택 결과와 난수 상태는 진행 저장에 포함해 새로고침·속도 변경으로 다시 뽑지 못한다.

### 2. 적과 자동전투

- 적마다 `전투 역할`, `특성명`, `방어`, `공격 패턴`, `전리품 표`를 가진다.
- 노상강도와 시간 도적은 첫 반격 강화, 멧돼지는 2번째마다 돌진, 호랑이 잔영은 3번째마다 강습, 약탈자는 중장 방어, 최종 그림자는 격턴 공명을 사용한다.
- 특성은 전투 시작 전에 짧게 설명하고, 발동한 턴에는 행동 배지와 전투 로그로 알린다.
- 플레이어 무기의 치명타·방어·타격 회복과 적의 방어·강공을 같은 상태 머신에서 결정적으로 계산한다.

### 3. NPC와 사건

- NPC는 모두 같은 회복이 아니라 서로 다른 도움을 준다.
  - 훈장: 작은 회복과 다음 전리품 조사 보정
  - 의원: 큰 체력 회복과 다음 방어 보정
  - 유물 기록원: 다음 공격과 전리품 조사 보정
- 사건도 역할을 나눈다.
  - 손질 도구함: 회복과 다음 방어 보정
  - 무예 기록: 다음 공격과 전리품 조사 보정
  - 발굴층 표식: 전리품 조사 보정
- 자동으로 해결되지만 받은 효과와 다음 전투에 남은 효과를 화면에서 확인할 수 있어야 한다.

### 4. 전리품

- 전리품은 명성·기록 조각과 별도로 종류와 수량을 가진다.
- 최소 6종을 `시간길 / 군영 / 청동 안개 / 최종층` 표로 나눈다.
- 적은 전리품을 주로 떨어뜨리고, NPC·사건은 특정 전리품 또는 발견 보정을 제공한다.
- 안전 귀환 전에는 `pendingLoot`이며 사망하면 잃는다.
- 안전 귀환하면 영구 탐사 창고로 옮긴다. 같은 정산 ID는 한 번만 적용한다.
- 전리품은 엽전으로 직접 판매하지 않고 탐사 준비물의 교환 재료로 사용한다.

### 5. 탐사 준비소

- 기존 복원 무기고를 `탐사 준비소` 안의 한 구역으로 유지한다.
- 준비소는 세 구역을 가진다.
  1. 탐사 준비물 구매
  2. 탐사 전리품과 준비물 교환
  3. 성공 기록 -2까지 무기 복원
- 준비물은 하나를 `다음 탐사에 장착`하고 탐사 시작 때 1개 소비한다.
  - 여행 붕대: 최대 체력 증가
  - 손질 천: 공격력 증가
  - 안전 주머니: 사망 엽전 손실 감소
- 구매·교환·장착 상태는 로컬 저장과 저장 데이터 파일에 포함한다.

### 6. 괴작

- 괴작은 전리품과 합치지 않는다. 강화 실패에서만 확률적으로 나온다.
- 최초 발견 기록은 판매 뒤에도 남고, 보유 조건 칭호는 실제 보유 수량을 따른다.
- 마지막 보유품 판매로 칭호가 비활성화될 때 버튼에서 미리 경고한다.
- 중복품은 한 개를 남기고 일괄 판매할 수 있게 하되, 영구 발견 기록과 이미 받은 보상은 유지한다.

## 저장 스키마

- 새 키 `weaponExpeditionEconomyV1`
  - `lootInventory`
  - `lootDiscovered`
  - `totalLootBanked`, `totalLootLost`
  - `supplies`
  - `equippedSupplyId`
  - `lastLootSettlementId`
  - `appliedTransactionIds`
- 활성 탐사에는 `pendingLoot`, `recentEncounterTypes`, `enemyTurnsTaken`, `playerTurnsTaken`, `activeEffects`, `usedSupply`를 저장한다.
- 기존 1.0 저장은 빈 경제 상태로 자동 이관한다.

## 완료 증거

1. 유형 확률과 개별 가중치가 분리되고 고정 시드로 재현된다.
2. 적 6종의 특성이 실제 피해·방어 계산에 영향을 준다.
3. NPC·사건의 서로 다른 효과가 한 번만 적용된다.
4. 전리품이 승리·귀환·사망에 따라 획득·보관·손실된다.
5. 상점 구매·교환·장착·소비·복원이 저장 후에도 유지된다.
6. 괴작 마지막 판매 경고와 중복 일괄 판매가 수량·칭호 규칙을 지킨다.
7. 전체 자동 검증, 밸런스 시뮬레이션, 데스크톱·태블릿·모바일 흐름이 통과한다.
