# Weapon Reinforce 탐사 1.0 구현 계획

> 상태: `1.0.0` 구현·검증 완료. 이 문서는 확정된 시스템 범위와 이후 회귀 기준으로 유지한다.

## 목표

서버 없이도 모바일·태블릿·웹에서 진행이 안전하게 남고, `퀴즈 → 강화 → 탐사 → 역사 기록 해금`이 하나의 닫힌 플레이 루프로 이어지는 1.0을 만든다.

## 확정 규칙

### 저장

- 브라우저 `localStorage`가 자동 저장의 기본이다.
- 진행 중 탐사는 매 상태 전환마다 체크포인트로 저장하고, 새로고침·탭 종료 뒤 같은 장면에서 재개한다.
- 저장 파일은 버전·생성 시각·허용된 키·체크섬을 포함한 JSON으로 내보내고 불러올 수 있다.
- 불러오기는 현재 브라우저 진행을 대체하며, 허용되지 않은 키와 손상된 파일은 거부한다.
- 서버·계정·클라우드 저장·랭킹은 사용하지 않는다.

### 탐사

- 탐사는 현대에서 청동기 시대로 내려가는 7개 역사층으로 구성한다.
- 역사층 순서는 고정하지만 각 층의 적·NPC·비전투 사건은 깊이·지역·가중치·최근 중복 방지 규칙으로 뽑는다.
- 첫 조우는 전투 규칙을 익힐 수 있도록 적으로 고정한다.
- 전투는 자동 교대 방식이며, 플레이어의 공격 연출이 끝난 뒤에 다음 턴 표시로 넘어간다.
- 조우 뒤 `안전 귀환`과 `더 깊이 탐사`는 사용자가 직접 선택한다.
- 자유 이동형 맵 대신 방문 완료·현재 위치·미탐사 상태가 보이는 7칸 경로를 사용한다.

### 보상과 실패

- 엽전의 주 수입원은 위인점프 퀴즈로 유지한다.
- 명성은 탐사 등급·칭호·지역 기록을 해금하는 누적 성취도다.
- 기록 조각은 검증된 무기·시대 역사 카드를 해금하는 데 쓴다.
- 안전 귀환 전 명성·기록 조각은 임시 전리품이다.
- 쓰러지면 임시 전리품을 전부 잃고, 보유 엽전 안에서 최대 200냥을 잃는다.
- `무기 손상`은 즉시 수리비를 치르는 사건으로 표현하고 강화 단계는 보존한다.
- 실제 내구도·영구 파괴·강화 단계 하락은 1.0 범위에서 제외한다.

### 교육과 완결

- 역사 사실과 게임 설정을 화면에서 분리한다.
- 각 역사 카드에는 시대·용도·핵심 특징·확실성·공식 자료 링크를 표시한다.
- 실제 역사 인물은 적으로 사용하지 않는다. 적은 도적·짐승·시간 잔영으로, NPC는 장인·기록자·훈장으로 구성한다.
- `+7 무기로 7층을 돌파해 안전 귀환`하면 시간 균열 봉합 완결 카드를 연다.

### 전투 화면

- 평상시는 왼쪽 아래 후방 상반신, 오른쪽에 적/NPC를 둔다.
- 공격 순간에는 후방 인물을 흐리거나 숨기고 팔·손·무기가 들어오는 1인칭 연출을 사용한다.
- NPC 조우에서는 무기를 낮추거나 감춘다.
- 무기마다 대기 파지점·크기·회전·공격 축·1인칭 위치를 데이터로 둔다.

## 구현 순서와 완료 증거

1. 저장 봉투·체크포인트·파일 내보내기/불러오기
   - 정상 왕복, 변조·과대 파일·알 수 없는 키 거부, 진행 중 탐사 재개 자동 검증
2. 가중 랜덤 조우와 7칸 지도
   - 후보 제한, 가중치, 첫 전투, 최근 중복 방지, 고정 시드 재현 검증
3. 역사 기록관과 보상 사용처
   - 조각 소비·중복 해금 방지·새로고침 보존 검증
4. 후방 반신/1인칭 전환과 무기별 연출
   - 7무기 × 데스크톱·태블릿·모바일 화면 검수
5. 최소 콘텐츠
   - 지역 3곳, 적 6종, NPC 3종, 비전투 사건 3종, 완결 1종
6. 출시 정리
   - 전체 검증, 프로덕션 base path, 런타임 자산 허용 목록, README·버전·체크리스트 동기화

## 1.0에서 하지 않는 것

- 서버 계정과 온라인 동기화
- 자유 이동형 오버월드
- 적 상성
- 실제 무기 내구도와 영구 파괴
- 장편 스토리와 토끼·자라 콘텐츠
- 경쟁 랭킹과 유료 기능
