# 조선 무장 출전(Deployment) 및 세이브(Save) 시스템 구현 계획

대장간에서 강화한 무기를 지니고 전장에 출전하여 활약상을 겨루는 "출전" 시스템을 도입하고, 플레이어 정보(엽전, 무기 등급, 무기 계열)를 로컬 스토리지에 저장하여 페이지를 새로고침하더라도 기존 게임 성과가 유지되도록 저장 기능을 통합 구현합니다.

## User Review Required

> [!IMPORTANT]
> **전장 출전첩의 페이지형(책장 넘기기) 구조 및 뉴스 속보 분리 연출**
> - **페이지형 화면 구성:** 
>   - 출전첩 화면은 책장을 넘기듯 **각 단계가 개별 페이지(1쪽, 2쪽, 3쪽...)**로 분할 렌더링됩니다.
>   - 각 단계 페이지는 해당 단계의 고유 로그와 연출 효과(타격 애니메이션)를 단독으로 보여줍니다.
> - **이전 단계 돌아보기 (Page-by-page Review):**
>   - 전투가 실시간으로 일어나는 동안이나 전투가 종결된 후에, 플레이어는 `◀ 이전 쪽` 및 `다음 쪽 ▶` 버튼 또는 상단의 스테이지 진행 현황 아이콘을 눌러 과거 돌파했던 단계들의 상세 전투 정보와 로그를 자유롭게 돌아볼 수 있습니다.
>   - 실시간 전투 진행 시에는 자동으로 가장 최신 전투가 벌어지는 쪽(Page)으로 자동 펼치기(Auto-flip)가 지원됩니다.
> - **뉴스 속보 독립 페이지 연출:**
>   - 전투 결과 정산 뉴스(대장간 일보 속보)는 전투 진행 모달 하단에 함께 노출되는 방식이 아니라, 출전이 최종 종료(패배 또는 이무기 처단 성공)되는 순간 **가장 마지막 별도 페이지(예: 3단계 패배 시 4쪽)**에 신문 속보 한 장 형태로 단독 렌더링됩니다.
>   - 플레이어는 이 독점 속보 페이지를 본 다음에도 원하면 `이전 쪽` 버튼이나 도트를 클릭해 각 단계별 활약상을 책 넘기듯 되돌아볼 수 있으며, 돌아갔다가도 마지막 쪽으로 오면 안전 귀환 버튼을 통해 퇴각할 수 있습니다.

  - `currentDeployPage` (현재 보고 있는 뷰어 쪽 번호: 1 ~ 8) 및 `maxReachedPage` (실제 전투가 완료된 최하단 쪽 번호) 상태 추가.
  - `deployLogs`를 단일 평탄 배열에서 **각 스테이지의 단계 번호를 키로 하는 객체** `{ 0: [...stage1Logs], 1: [...stage2Logs] }`로 개편하여 단계별 로그 독립 보존.
- **출전 진행 딜레이 연동:**
  - 새로운 단계에 진입할 때마다 `deployStep = index`, `currentDeployPage = index + 1`, `maxReachedPage = index + 1`로 자동 세팅하여 화면을 그 단계 쪽수로 강제 전환합니다.
  - 패배하거나 승리하여 전투가 완전히 종료되는 즉시 최종 뉴스 페이지인 `currentDeployPage = (최종 도달 단계 + 1)` 쪽으로 넘겨 단독 뉴스 속보를 펼쳐 줍니다.
- **UI 및 페이지 점프 컨트롤러 구현:**
  - 모달 본문을 고풍스러운 서적/전투 일지(Book Spread/Ledger) 디자인으로 구상.
  - 하단에 `◀ 이전 쪽`, `다음 쪽 ▶` 단추 및 현재 쪽에 대한 쪽수 카운터(`currentDeployPage / totalPages`) 렌더링.
  - 상단 진행 상황 표시바의 도트를 누르면 `currentDeployPage`가 해당 단계 번호로 변경되어 직접 페이지 전환.

## Verification Plan

### Automated / Build Verification
- `npm run build`를 실행하여 번들이 구문 오류 없이 온전히 빌드되는지 확인.

### Manual Verification (Browser-based)
- **페이지 전환 테스트:**
  1. 출전 개시 후 1단계 들고양이 소탕에 들어가면 '1쪽'이 펼쳐지며 전투가 시작되는지 검증합니다.
  2. 1단계 성공 후 2단계 지리산 멧돼지 전투로 넘어갈 때 자동으로 '2쪽'이 열리고 2단계의 새로운 적 및 로그가 출력되는지 검증합니다.
  3. 전투가 끝나기 전 혹은 후에 `◀ 이전 쪽`을 눌러 1쪽(1단계 완료 정보)을 다시 들여다볼 수 있는지 체크합니다.
- **뉴스 속보 독립 페이지 검증:**
  1. 전투가 패배하거나 최종 클리어로 종결되었을 때, 신문 기사 속보 화면만 독립적으로 나타나는 최종 페이지로 자동 전환되는지 확인합니다.
  2. 속보 화면에서는 '안전 귀환' 버튼이 독점적으로 보이고, 이전 페이지로 이동하면 귀환 버튼 대신 '쪽수 넘기기'만 가능한지 확인합니다.
